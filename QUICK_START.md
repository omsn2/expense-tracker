## 🚀 Quick Start

1. **Add Income**
   - Go to Income page
   - Click "Add Income"
   - Enter salary, freelance, etc.

2. **Set Budgets**
   - Go to Budgets page
   - Click "Add Budget"
   - Set category limits

3. **Track Expenses**
   - Go to Expenses page
   - Click "Add Expense"
   - Log your spending

4. **Automate Bills**
   - Go to Recurring page
   - Use templates or create custom
   - Bills auto-generate monthly

5. **Enable Notifications**
   - Go to Settings page
   - Toggle "Smart Reminders"
   - Get budget & bill alerts

---

## 💾 Backup Your Data

**Monthly Backup:**
1. Go to Settings
2. Click "Download Full Backup"
3. Save JSON file to cloud storage

**Export to Excel:**
1. Go to Settings
2. Click "Export Expenses/Income/Budgets"
3. Open CSV in Excel/Google Sheets

## 🆘 Troubleshooting

**App not loading?**
- Check Vercel dashboard for errors
- Verify backend URL in frontend .env.production

**Data not saving?**
- Check browser console for errors
- Verify API endpoints are working

**Notifications not working?**
- Enable in Settings
- Allow browser permissions
- Check notification settings
